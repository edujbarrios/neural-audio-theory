# Sonauto API moved to Treblo

Sonauto has rebranded to Treblo, and the official developer documentation now uses Treblo domains. Continue to the current [Treblo API guide](./treblo-api.md).

Existing integrations should replace `api.sonauto.ai` with the current base URL documented by Treblo and revalidate request fields before deployment.
